<analysis>**original_problem_statement:**
The user wants to build a full-featured Telegram subscription management bot.

**PRODUCT REQUIREMENTS:**
- **Telegram Bot:**
    - Show subscription plans with inline buttons in the chat.
    - Handle plan selection and payment flow (initially manual QR, with Razorpay as an option).
    - Allow users to submit payment screenshots.
    - Automatically add verified subscribers to private Telegram channels.
    - Each subscription plan can be linked to a different private channel.
    - Automatically send renewal reminders with a Renew button before subscription expiry.
    - Provide a grace period after expiry.
    - Automatically remove users from channels after the grace period if they don't renew.
    - Send automated follow-up messages.
    - Provide a  command that generates a shareable message with a button.
- **Admin Dashboard (Web UI):**
    - A full dashboard to manage the bot.
    - CRUD functionality for subscription plans, including setting a specific Channel ID for each plan.
    - A page to view subscribers.
    - A Payments page to see pending payments, view user-submitted screenshots, and verify payments.
    - An analytics dashboard.
    - A settings page to configure the bot token, channel IDs, etc.
- **SaaS Model for the Dashboard:**
    - The dashboard itself should be a subscription-based service.
    - The first user to register becomes the super admin.
    - All subsequent users must subscribe to a plan (e.g., monthly, yearly, lifetime) to use the dashboard.
    - The super admin needs a special Admin Support Dashboard to manage all other users' dashboard subscriptions.
    - Dashboard subscriptions should automatically expire and prompt users for renewal.
